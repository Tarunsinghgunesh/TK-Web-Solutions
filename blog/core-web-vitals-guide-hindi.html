Core Web Vitals Guide 2026: LCP, INP Aur CLS Score Green Kaise Karein

📅 2026 By Tarun Singh ⏱ 10 min read

⚡ Quick Takeaway / Summary

Core Web Vitals Google ke 3 official speed aur user experience metrics hain: LCP (Loading speed), INP (Click response speed), aur CLS (Visual stability). Agar aapki website in teeno metrics par green score karti hai, toh Google search ranking mein seedha technical advantage milta hai.

1. Core Web Vitals Kya Hain Aur Google Kyun Itna Focus Kar Raha Hai?

Pehle zamane mein Google sirf yeh dekhta tha ki page ka poora size kitna hai. Lekin Google ne realise kiya ki asal me user experience is baat par depend karta hai ki screen par pehla main content kitni jaldi dikha, button dabane par phone ne kitni jaldi respond kiya, aur kya page load hote waqt buttons aage-peeche jump kar rahe the.

Is real-world experience ko measure karne ke liye Google ne Core Web Vitals (CWV) launch kiya. Yeh data Google Chrome browser chalane wale real users (CrUX report) se collect hota hai.

2. LCP (Largest Contentful Paint) Kya Hai Aur Kaise Sudharein?

LCP measure karta hai ki screen ke viewport mein sabse bada element (jaise hero image, banner, ya bada H1 title) kitni der mein poori tarah render hua:

  • Good Target: 2.5 seconds se kam.
  • Poor Score: 4.0 seconds se zyada.
  • Fix Kaise Karein: Hero image ko compress karke WebP format use karein, Google Fonts par rel="preconnect" lagayein, aur render-blocking CSS/JS files ko defer karein.

3. INP (Interaction to Next Paint): Naya 2026 Metric FID Ki Jagah

Google ne purane First Input Delay (FID) ko officially replace karke INP (Interaction to Next Paint) lagu kar diya hai. INP yeh dekhta hai ki jab user kisi button, mobile hamburger menu ya dropdown par tap karta hai, toh browser agla frame render karne mein kitna delay karta hai:

  • Good Target: 200 milliseconds se kam.
  • Fix: Bhaari third-party JavaScript scripts (jaise heavy trackers, unoptimized chatbots) ko hatao ya lazy-load karo.

4. CLS (Cumulative Layout Shift): Jumping Elements Ko Kaise Rokein?

Aapne aksar dekha hoga ki aap kisi link par click karne wale hote hain, tabhi upar se ek image load hoti hai aur link neeche khisak jaata hai, aur galti se kisi aur ad par click ho jaata hai! Ise kehte hain Layout Shift:

  • Good Target: 0.1 se kam score.
  • Fix: Har image aur video par hamesha explicit width aur height attributes specify karein taaki browser pehle se space reserve kar le.

5. Core Web Vitals Benchmark Threshold Table

Metric Kya Measure Karta Hai Good (Green) Needs Improvement (Orange) Poor (Red)
LCP Largest Contentful Paint (Loading) ≤ 2.5 s 2.5 s – 4.0 s > 4.0 s
INP Interaction to Next Paint (Responsiveness) ≤ 200 ms 200 ms – 500 ms > 500 ms
CLS Cumulative Layout Shift (Visual Stability) ≤ 0.1 0.1 – 0.25 > 0.25

6. 5-Step Practical Speed Optimization Blueprint

  1. Test Your Site: pagespeed.web.dev par jakar apni website ka live mobile score dekhein.
  2. Compress Images: Squoosh.app ya TinyPNG se sabhi images ko 100KB ke andar laayein.
  3. Defer Unused JavaScript: Analytics aur AdSense scripts ko async ya defer karke load karein.
  4. Browser Caching: Static assets (CSS, JS, Fonts) par minimum 6 mahine ka cache header lagayein.
  5. Clean HTML Structure: Deep nested div elements hatayein aur clean semantic HTML use karein. Mazeed detail ke liye padhein humara Website Speed Guide.

Kya Core Web Vitals fail hone se Google rank drop ho jaati hai?

+

Core Web Vitals test karne ka best free tool kaunsa hai?

+
Google PageSpeed Insights aur Google Search Console ka Core Web Vitals report sabse accurate official tools hain.

+
Mobile devices ke processors slow hote hain aur mobile 4G network par latency hoti hai, isliye mobile score desktop se zyada strict hota hai.
